# Loan Management System

A full-stack Loan Management System built using ASP.NET Core.

## Projects
- LoanAPI - REST API using ASP.NET Core Web API and Entity Framework Core
- LoanMVC - ASP.NET Core MVC frontend

## Features
- JWT-based user authentication and secure login
- Role-based authorization (Admin & Customer)
- Customer registration and profile management
- Loan application, approval, and rejection workflow
- Automatic EMI schedule generation
- EMI payment processing and payment history
- Document upload and management
- Secure password hashing with BCrypt
- Session-based authentication for the MVC client
- RESTful API built using Repository-Service architecture
